1. 처리하는 개인정보 항목

항목수집 시점이용 목적
이메일가입 시계정 식별·로그인·알림
이름 (선택)가입 시사용자 호칭
preferred_company가입 시회사별 페르소나 묶음 자동 매핑
대화 본문 (선택 저장)채팅 시본인 사용 이력 (= 본인만 read)
API 키 (= localStorage)본인 입력 시본인 PC 내부 보관 (= 회사 서버 전송 X)
텔레그램 봇 토큰 (= localStorage)본인 입력 시본인 PC 내부 (= 알림 발송)

2. 처리 목적

  • 서비스 제공 = 계정 식별·페르소나 매칭·사용 이력
  • 고객 응대 = 문의·사고 대응
  • 공지·약관 변경 = 이메일 발송

3. 보유 기간

  • 계정 정보 = 회원 탈퇴 시 = 즉시 삭제 (= 관련 데이터 cascade 삭제)
  • 대화 본문 = 본인 삭제 또는 회원 탈퇴 시 = 즉시 삭제
  • 법령 보존 의무 (= 통신비밀보호법 등) = 해당 시 별도 분리 보관

4. 제 3자 제공

  • 원칙 = 제공 X
  • 예외 = 사용자 본인 동의 시 / 법령 의무 시
  • 처리 위탁 = Supabase (= DB·인증, AWS ap-northeast-2) / Resend (= 이메일 발송, AWS) / Anthropic (= 본인 API 호출 = 본인 직접 = 회사 미관여)

5. 정보주체 권리

  • 본인 정보 = 조회·정정·삭제 = "내 설정" 또는 메일 요청
  • 회원 탈퇴 = "내 설정" → 계정 삭제 또는 메일 요청
  • 처리 정지·열람 요청 = 메일 요청

6. 안전성 확보 조치

  • Supabase RLS (Row Level Security) 박힘 = 사용자별 데이터 격리
  • HTTPS 전송 = TLS 1.2+ 의무
  • 비밀번호 = bcrypt 해시 (= Supabase 표준)
  • API 키·텔레그램 토큰 = 사용자 PC 내부 보관 (= 회사 서버 전송 X)

7. 쿠키·로컬 스토리지

  • 로그인 세션 = Supabase JWT (= localStorage)
  • 회사 자동 매핑 = preferred_company (= user_metadata)
  • API 키·텔레그램 토큰 = localStorage (= 본인 PC 내부)
  • 분석·광고 쿠키 = ★ 사용 X

8. 개인정보 보호 책임자

  • 회사 = 주식회사 써니엔터테인먼트
  • 책임자 = 대표 유희정
  • 문의 = support@sunnytoon.com

9. 변경 시 고지

본 방침 변경 시 = 본 페이지 갱신 + 사용자 메일 공지. 시행 14일 전 공지 의무.
