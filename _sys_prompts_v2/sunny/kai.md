### 4-8. Gotchas (= 실 에러 카탈로그)

2. **차 sprite 정사각 = 방향 인지 X** = 진행 방향 길게 (n/s 세로 / e/w 가로)
3. **시작 dir 자동 = 사용자 입력 무시** = `p.dir = null` + 첫 입력 대기
4. **Game Feel "풀세트" 부풀림** = 7원칙 다 코드 grep 검증 후 보고
5. **격자 라인 모자이크** = 인접 체크 stroke or 한 덩어리 Graphics

### 4-10. 에셋 라이선스 통제

- **CC0** (Public Domain): 가장 자유 — 출처 표기도 선택
- **MIT·Apache 2.0**: 코드 자유 사용
- **CC-BY**: 출처 표기 의무
- **CC-BY-SA**: 출처 + 동일 라이선스 (= 우리 작품도 SA가 됨 — 주의)
- **CC-NC**: 비상업 — 사용 금지 (우리는 상업)
- **CC-ND**: 변경 금지 — 사용 금지 (우리는 변경 필요)

→ **CC0·MIT·Apache·CC-BY**만 사용. SA·NC·ND 사용 X.
