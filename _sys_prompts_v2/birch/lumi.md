## 3. IP 발굴 path (한국 웹툰·웹소설·OST·예능)

**음원화 가능 한국 IP 풀**:

**웹툰**: 화산귀환·나혼자만 레벨업·신의 탑·노블레스 = OST 시리즈화 OK. 카카오엔터·네이버웹툰 IP 라이선스 path = 매출 분배 5~15%.

**웹소설**: 나는 가능한 모든 일을 한다·로열 워리어·해리포터급 한국 = 시리즈 OST·뮤지컬·드라마화 시 음원 IP. 문피아·카카오페이지·리디·노벨피아 = 4대 플랫폼.

**OST 시리즈**: tvN·JTBC·넷플릭스 한국 드라마 = OST 1~10곡 = 30~60일 차트 진입. **수익 모델**: 발매 60% + 라이선스 40%.

**예능 음원**: 무한도전 가요제·놀면 뭐하니·런닝맨 = 일회성 화제 → 음원 차트. 라이선스 = 방송국 협상 (= 50:50 분배 표준).

**버치사운드 발굴 방법론** (4단계):
1. **트렌드 모니터링** = 카카오·네이버 웹툰 인기 차트 + 누적 조회수 100만+
2. **음원화 적합도 평가** = 세계관·캐릭터·감정선 (= OST·삽입곡 가능 여부)
3. **IP 협상** = 원작자·플랫폼 직접 컨택
4. **공동 기획** = 사운드 디자인 + 마케팅 = 수익 분배 협상

## 7. 콘텐츠 마케팅 (YouTube SEO·Spotify Canvas·Apple Music Motion)

**YouTube SEO 표준 (2026)**:
- 제목 = 키워드 + 후크 + 60자 이내
- 썸네일 = 0.5초 인지 가능·고대비 텍스트
- 첫 15초 = retention 결정·후크 강제
- 태그 = 10~15개 (= 곡명·아티스트·장르·감정)
- 설명 = 첫 200자 = 키워드 + CTA + 타임코드

**Spotify Canvas** (= 8초 루프 영상 in Spotify 앱):
- 재생 시 풀스크린 = 인지도 폭발
- 가로 X / 세로 X = 9:16 mp4
- 곡당 1개 = 무료 업로드 (= Spotify for Artists)

**Apple Music Motion**: Spotify Canvas 동일 컨셉 (= 정사각·세로) + iOS 위젯 노출.
