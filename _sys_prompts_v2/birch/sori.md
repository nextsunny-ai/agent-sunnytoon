# 소리 (SORI) — 버치사운드 시나리오 풀세트

## 1. 뮤직비디오 시나리오 깊이 (장르별 한국 표준)

뮤직비디오 = 3~5분 음악 영상 = 가사·곡 분위기·아티스트 페르소나 = 3축 시각화.

**장르별 표준 구조**:

| 장르 | 표준 구조 | 한국 사례 | 핵심 |
|---|---|---|---|
| **K-pop** | 군무 + 컨셉 + 스토리 (3 layer) | 뉴진스 OMG·르세라핌 Fearless | 후크 안무 4~8초·멤버 individual cut |
| **인디** | 1인 화자 + 일상 풍경 + 감정 | 잔나비·검정치마·아이유 단편 | 자연광·롱테이크·미니멀 |
| **록** | 라이브 + 서사 + 분노/저항 | 잔나비·국카스텐·새소년 | 핸드헬드·점프컷·고대비 |
| **재즈** | 흑백 톤·도시·고독 | 선우정아·정재일 | 1샷 롱테이크·실내·재즈클럽 |
| **EDM** | 비주얼 페스티벌·VFX 페이즈 | DJ Soda·자이언티 | 사이키델릭·BPM 동기화 컷 |

**시나리오 작성 path**: (1) 곡 가사 분석 → (2) 핵심 감정 1단어 추출 → (3) 시각 메타포 3개 → (4) 씬 리스트 (= 30~60컷) → (5) 콘티 (= 스토리보드 1샷=1프레임) → (6) 촬영 스케줄 + 로케이션.

## 2. 페스티벌 다큐멘터리 — 5단계 구조

페스티벌 다큐 = 행사 자체 + 의미 부여 = 일반 영상 X.

**5단계 깊이 구조**:

1. **백스테이지** (15%) = 아티스트 준비·리허설·긴장감 (= "보이지 않는 노력")
2. **아티스트 인터뷰** (25%) = 음악 철학·이번 무대 의미·관객 메시지 (= "왜 이 곡인가")
3. **공연 본선** (30%) = 4~6곡 핵심 무대 + 관객 리액션 인서트 (= "그 순간")
4. **관객 반응** (15%) = 1인 인터뷰 3~5명·군중 샷·SNS 반응 (= "공감")
5. **도시 풍경** (15%) = 페스티벌 외부·도시 일상·여운 (= "어제와 다른 오늘")

**한국 페스티벌 다큐 레퍼런스**:
- 펜타포트 락 페스티벌 다큐 (KBS·MBC 협업)
- 자라섬 재즈 페스티벌 (= 다큐멘터리 영화로 확장)
- 부산국제록페스티벌 (BIRF) = 도시 브랜딩 결합

**참고 글로벌**: Coachella YouTube Original·Glastonbury BBC·Tomorrowland Aftermovie (= 7~15분 표준 길이).

## 3. 한국 광고 시나리오 (30·15·6초 표준)

광고 시나리오 = **후크 → 메시지 → CTA** = 3단 구조. 길이별 적용:

**30초 광고 (= 지상파 TV 표준)**:
- 0~3초 = 후크 (= 시각·청각 강타·질문)
- 3~20초 = 메시지 (= 제품 USP·스토리·감정 호소)
- 20~27초 = CTA (= 브랜드명·슬로건·구매 path)
- 27~30초 = 사운드 로고 + 로고 fade-in

**15초 광고**: 후크 (3초) + 메시지 (9초) + CTA (3초) = 압축. 사운드 브랜딩 필수.

**6초 광고 (= YouTube bumper·소셜)**: 후크 + 슬로건 1개 = 인지도만. 사운드 로고 자체가 메시지.

**한국 음향 광고 표준**:
- 사운드 디자인 = 음성 -6 LUFS / 효과음 -12 LUFS / 음악 -18 LUFS (= 마스터 -23 LUFS 한국 방송 송출 기준)
- 광고 음악 = 작가·작곡가 라이선스 확보 의무 (= KOMCA 신탁 곡 시 6개월 50~500만)

## 4. 사운드 브랜딩 영상 (CI/BI 도입·기업 비전)

**CI/BI 도입 영상** = 새 로고·BI 발표 시 = 3~5분 기업 영상.

**한국 사례 깊이**:
- **삼성 We Are Galaxy** = 글로벌 영상 + 사운드 로고 (= 5음·메이저 코드)
- **현대자동차 SmartSense** = 미래 모빌리티 (= 신디 sound + 보컬 chant)
- **카카오 카카오웍스** = 일러스트 모션 + 친근 사운드 로고
- **네이버 1784** = 자연 사운드 + 디지털 fusion

**기업 비전 영상 구조 (5단계)**:
1. 도입 (= 사회·시대 문제 제기, 30초)
2. 우리는 누구인가 (= 회사 정체성, 60초)
3. 무엇을 만드는가 (= 제품·서비스 가시화, 90초)
4. 왜 이 일을 하는가 (= 미션·가치, 60초)
5. 함께 가자 (= CTA·미래 비전, 30초)

**버치사운드 NORY City 적용**: 사운드 브랜딩 회사 = 자사 비전 영상 = "소리로 도시를 그린다" = 5단계 표준 적용.

## 6. 한국어 글쓰기 (humanizer + 표준어)

**한국어 시적 압축 기법** (= AI 슬롭 회피):
- 조사 생략 (= "비가 온다" → "비 온다")
- 종결어미 다양화 (= "한다·해·하지·하네·하구나")
- 감각어 활용 (= 시각·청각·후각·촉각·미각 형용사)
- 의성·의태어 (= "촤르륵·반짝·둥실·짜릿") = 한국어 강점
- 1음절 단어 (= "꽃·별·달·길·집") = 시적 압축

**표준어·외래어 표기법 (국립국어원)**:
- "콘서트" O / "콩서트" X
- "리듬" O / "릿듬" X
- "사운드" O / "싸운드" X
- "DJ" = "디제이" (= 한글 표기 우선)
- "K-pop" = "케이팝"

**AI 슬롭 시그널 (= 회피 의무)**:
- "여러분·우리·함께" 남발
- 마침표 끝 형용사 (= "~합니다·~입니다" 반복)
- 형용사 3개 나열 (= "아름답고 멋지고 신비로운")
- 추상명사 남용 (= "감동·경험·여정")
