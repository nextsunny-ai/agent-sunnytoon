# 하나 (HANA) — 버치사운드 회계·법무·세무 풀세트 (한국 2026 기준)

## 1. 한국 음원 라이선스 단체 풀세트 (각 단체 차이 + 사용 path)

한국 음원 라이선스 = 4개 신탁관리단체 + 1개 비신탁 = 권리별 분리 징수.

| 단체 | 관리 권리 | 사용처 | 2026 단가 (페스티벌·공연 기준) |
|---|---|---|---|
| **KOMCA** (한국음악저작권협회) | 작사·작곡·편곡 (= 저작권) | 공연·방송·온라인·복제 | 공연 매출 3.0% (1만 명 미만) / 3.6% (1만+) |
| **KOSCAP** (한국음악실연자연합회) | 실연자 (= 가수·연주자 보상금) | 디지털 음원·방송·공연 | 공연 매출 0.6~1.2% |
| **KAA** (한국음반산업협회 = RIAK) | 음반제작자 (= 마스터 권리) | 디지털 음원·방송·복제 | 음원 단가 = 7원/스트림 (2026 표준) |
| **FMA** (함께하는음악저작인협회) | KOMCA 비가입 작가 (= 신탁 거부 작가) | 공연·방송·온라인 | KOMCA와 동일 단가 |
| **하슬라뮤직** | 비신탁 직접 관리 | 신크·광고·드라마 | 협상가 (= 곡당 50~500만 원) |

**핵심**: 페스티벌 = KOMCA + KOSCAP + KAA = 3중 신청 의무. 신청 = 공연 60일 전 KOMCA `www.komca.or.kr` → 공연사용료 신청서 + 셋리스트 + 예상 관객 수 제출.

## 2. 신크 라이선싱 (Sync Licensing) — MMA 한국 표준 + 가격대

광고·드라마·영화·게임 = **Master 라이선스 + Sync 라이선스 = 2종 동시 취득** 의무.

**MMA (Master + Sync) 표준 항목**:
1. 사용 범위 (= 지역·매체·기간)
2. 독점 여부 (Exclusive vs Non-exclusive)
3. 사용 길이 (= 5초·15초·30초·풀곡)
4. 영상화 권리 (Audio-visual sync rights)
5. MFN clause (Most Favored Nations = 다른 권리자 동일 단가)

**2026 한국 가격대**:
- 광고 (= 지상파 TV 6개월) = 마스터 1000~5000만 / 신크 500~3000만 (= 곡당 1500~8000만 총합)
- 드라마 OST 삽입곡 (= 1회분) = 마스터 300~1500만 / 신크 200~800만
- 유튜브 광고 (= 1년·글로벌) = 마스터 200~1000만 / 신크 150~600만
- 게임 BGM (= 영구·플랫폼 무제한) = 마스터 500~3000만 / 신크 300~2000만
- 다큐멘터리 (= 케이블·1년) = 마스터 100~500만 / 신크 50~300만

## 3. 페스티벌 운영 계약 표준 항목

**아티스트 출연 계약 (Performance Agreement)**:
- 출연료 + 부대비 (= 항공·숙박·식비·라이더)
- 라이더 (= Technical Rider + Hospitality Rider)
- Pyrotechnic·video projection·special effect 사용권
- 매니지먼트·앨범사 동의서
- 위약금 조항 (= 천재지변 제외·일방 취소 시 위약금 100~200%)
- 출연료 지급 = 공연 30일 전 50% + 공연 당일 50%

**스폰서 계약 (Sponsorship Agreement)**:
- Tier (Title·Presenting·Official·Supporting)
- 브랜딩 노출 권리 (= 무대·LED·티켓·웹사이트·SNS)
- 카테고리 독점 (Exclusivity)
- Activation 권리 (= 부스·체험존)
- ROI 보고서 의무

**장소 임대 계약**: 보증금 + 임대료 + 원상복구·보험 (= 공연 배상책임보험 10억 이상 표준)

**F&B 계약**: 매출 수수료 (= 15~25%) + 위생·식품안전 인허가 의무자 명시

## 4. AI 음원 저작권 — KOMCA 2026-03-24 정책 본문

KOMCA 2026-03-24 발표 = "AI 생성 음원 저작권 등록 가이드라인 v1.0":

1. **AI 단독 생성 = 등록 불가** (= Suno·Udio 단독 출력물)
2. **AI + 인간 협업 = 등록 가능** (= 인간 기여도 30% 이상 입증)
3. **입증 자료**: 프롬프트 로그 + 편집 과정 (= DAW 프로젝트 파일) + 인간 작업 시간 기록
4. **표기 의무**: 등록 시 "AI 협업 (도구명·기여도 %)" 명시
5. **신탁 가능**: 인간 협업 입증 시 = KOMCA 신탁 OK

**미국 USCO·일본 JASRAC 차이**: 미국 = 인간 저작자성 요구 (= AI 단독 거부) / 일본 = 사례별 심사. 한국 = 중간 (= 협업 입증 시 OK).

## 5. 사운드 브랜딩 IP — 소리상표 + 저작권 차이

**소리상표 (Sound Mark)** = 브랜드 사운드 로고 (= 인텔 차임·넷플릭스 따단·맥도널드 휘파람) 등록.

- **한국 KIPRIS** (= 특허청): 출원료 56,000원 / 등록료 211,000원 (10년) / 갱신 가능
- **미국 USPTO**: TEAS Plus $250 / TEAS Standard $350 (= 글로벌 보호)
- **마드리드 협정 출원**: WIPO 경유 = 한 번에 다국 등록 ($653 + 국가별 추가)

**저작권 차이**: 저작권 = 자동 발생 (= 등록 불요) / 소리상표 = 등록 필수 + 식별력 입증 의무.

**버치사운드 필수**: NORY City 사운드 로고 = 소리상표 + 저작권 + KOMCA 신탁 = 3중 보호.
