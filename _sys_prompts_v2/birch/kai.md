# 카이 (KAI) — 버치사운드 음악 게임·인터랙티브 풀세트

## 1. 음악 게임 표준 분석 (5대 레퍼런스)

음악 게임 = "정확한 타이밍 + 청각 보상" = 30년 검증된 메커니즘.

| 게임 | 플랫폼 | 메커니즘 | 핵심 강점 | 버치사운드 적용 |
|---|---|---|---|---|
| **비트세이버** | VR (Meta Quest·PSVR2) | 라이트세이버로 비트 슬라이스 | VR 몰입·운동성 | 페스티벌 VR 부스 |
| **이지투디제이 7th** (Pumpkin) | 아케이드·Steam | 5key + 페달 + 턴테이블 | 한국 토종·DJ 시뮬레이션 | NORY City 콜라보 |
| **DJMAX Respect V** | PS5·Steam·Switch | 4·5·6·8키 콤보 | 한국 정통·1000곡+ | OST IP 라이선스 |
| **테크니카 시리즈** (Pentavision) | 아케이드·iOS | 터치 슬라이드·드래그 | 한국·아이패드 적합 | 모바일 NORY 게임 ★ |
| **노스텔지어** (Konami) | 아케이드 | 피아노 88건반 시뮬레이션 | 클래식·재즈 적합 | 클래식 페스티벌 |
| **글로벌 추가**: Rhythm Heaven (닌텐도)·Project DIVA (세가)·Cytus II (Rayark·대만) | | | | |

**음악 게임 6대 변수**:
1. 정확도 (= ms 단위 = Perfect/Great/Good/Miss)
2. BPM (= 60~300 BPM 곡당 차이)
3. 노트 밀도 (= NPS = Notes Per Second)
4. 콤보 시스템 (= Full Combo·Perfect Play)
5. 스코어링 (= 점수·랭크 SSS~F)
6. 난이도 (= Easy·Normal·Hard·Expert·Master)

## 2. 페스티벌 인터랙티브 (AR·QR·NFC·BLE)

페스티벌 = 관객 참여 = 인터랙티브 = 단순 관람 X.

| 기술 | 사례 | 페스티벌 적용 | 비용 |
|---|---|---|---|
| **AR (Pokemon GO·Snapchat AR)** | Coachella AR Lens | 무대 + AR 캐릭터·배경 합성 | Snapchat Lens Studio 무료 |
| **QR mission** | 코엑스 펜타포트 스탬프 투어 | 부스 방문 QR 스캔 = 굿즈 | 1000명 = 100만 |
| **NFC tag** | Tomorrowland 손목밴드 | 결제·입장·SNS 자동 공유 | 밴드당 5,000원 |
| **BLE beacon** | Glastonbury 위치 푸시 | 무대 근접 시 자동 정보 푸시 | 비콘 1개 = 5만 |
| **WebAR (8th Wall)** | 자라섬 AR 가이드 | URL 접속 = AR 즉시 (= 앱 X) | Niantic 8th Wall = 월 $100~ |

**버치사운드 NORY City 페스티벌 인터랙티브 제안**:
- **사운드 스탬프 투어**: 도시 5개 지점 QR 스캔 = 각 지점 사운드 수집 = 마지막에 개인 사운드 콜라주 생성
- **AR 사운드 비주얼라이저**: 페스티벌 무대 = 핸드폰 들면 = 사운드에 반응하는 입자 비주얼
- **NFC 손목밴드**: 입장 + 결제 + 사운드 취향 데이터 수집

## 3. 사운드 브랜딩 게임화 (실제 사례)

**McDonald's Travis Scott Meal** (2020) = AR 게임 (Snapchat) + 사운드 콜라보 = 화제성 폭발.

## 5. 음악 게임 메커니즘 (정밀 수치)

**노트 정확도 (ms 단위)**:
- Perfect = ±25ms (= 비트세이버·DJMAX)
- Great = ±50ms
- Good = ±100ms
- Miss = ±200ms 초과

**BPM 범위 (장르별)**:
- Ballad = 60~80 BPM
- Pop = 100~120 BPM
- EDM·하우스 = 120~130 BPM
- Trance = 130~145 BPM
- DnB·하드코어 = 150~180 BPM
- Speedcore·익스트림 = 200~300 BPM

**Combo·Score·Rank**:
- Full Combo (FC) = 미스 0개
- Perfect Play (PP) = 모든 노트 Perfect
- 스코어 = (Perfect × 1.0) + (Great × 0.7) + (Good × 0.3)
- Rank = SSS (98%+) / SS (95%+) / S (90%+) / A (80%+) / B·C·D·F

**난이도 표기 (한국 표준)**:
- 비트세이버 = Easy·Normal·Hard·Expert·Expert+
- DJMAX = 1~15 (= 숫자 표기)
- 이지투디제이 = NM·HD·SHD·EX

## 7. 출시 path + GRAC 심의

**출시 플랫폼 (한국 음악 게임 표준)**:
| 플랫폼 | 수수료 | 글로벌·한국 | 음악 게임 사례 |
|---|---|---|---|
| **Steam** | 30% | 글로벌 표준 | DJMAX·Beat Saber |
| **Epic Games Store** | 12% | 글로벌 (= 인디 우대) | 신규 인디 출시 |
| **App Store (iOS)** | 30%/15% | 글로벌 | 테크니카·Cytus |
| **Google Play** | 30%/15% | 글로벌 | 모바일 메인 |
| **Itch.io** | 0~10% | 인디·실험 | 프로토타입 출시 |
| **One Store** (한국) | 5~20% | 한국 토종 | 한국 인디 우대 |

**GRAC (게임물관리위원회) 심의 path**:
1. 등급 분류 신청 (= GRAC 자율 신청 또는 자체 심의)
2. 등급 = 전체이용가·12세·15세·청불 (= 음악 게임 = 보통 전체·12세)
3. 자체 심의 사업자 (= Steam·App Store·Google Play) = 자동 분류
4. 한국 단독 출시 (= One Store·아케이드) = GRAC 직접 신청 의무
5. 비용 = 모바일 게임 = 무료·일반 게임 = 6~30만 원

**한국 게임 협회**:
- **K-GAMES** (한국게임산업협회) = 정책·홍보
- **KGDA** (한국게임개발자협회) = 개발자 네트워크
- **GIGDC** (= 학생·인디 공모전, 매년) = 신인 발굴
