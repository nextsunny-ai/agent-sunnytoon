텔레그램 알림 설정

에이전트 답변을 본인 텔레그램으로 모바일 푸시 알림.

왜 본인 봇?
• 본인 봇 = 본인만 사용 = 안전 + 본인 통제
• 1번만 만들면 영구 사용
사용자 가이드 (= 처음 1번만)

[1단계] 본인 봇 만들기 (= 1분)

  1. 텔레그램 = @BotFather 클릭·시작
  2. 채팅창에 = /newbot 입력
  3. 봇 이름 입력 = 예: "NEXTART AI 알리미" (= 자유 한국어 OK)
  4. 봇 username 입력 = 예: nextart_kim_bot (= 반드시 영문 + _bot으로 끝)
  5. BotFather가 = 봇 토큰 알려줌 = 7654321:AAH-ABC... 형식 = 긴 문자열 전체 복사

[2단계] 본인 봇 시작

  1. 방금 만든 봇 username 텔레그램 검색 (= 예: @nextart_kim_bot)
  2. 봇 채팅 들어가서 = "시작" 누르거나 = "안녕" 메시지 1개 보내기
  3. = 본인 봇 활성화 완료

[3단계] 본인 chat_id 확인

  1. 텔레그램 = @userinfobot 클릭·시작
  2. 봇이 = 본인 ID 표시 = Id: 1234567890 형식
  3. = 그 숫자 (= 9~10자리) 복사

[4단계] 아래에 입력 + 테스트

  1. 봇 토큰 = 위에서 복사한 거 붙여넣기
  2. chat_id = 본인 ID 숫자 붙여넣기
  3. ☑ 활성화 체크 → "테스트 발송" 클릭
  4. 본인 봇 채팅 = "✅ 연결 성공" 메시지 확인되면 = "저장"
  5. = 끝. 이후 = 에이전트 답변 = 자동 푸시
• 저장 = 본인 브라우저 localStorage에만 저장 (= 우리 서버 X)
• 알림 끄려면 = ☐ 체크 해제 또는 = 본인 봇 끄기
• 다른 기기에서 사용 = 각 기기마다 한 번씩 설정 (= 보안)
